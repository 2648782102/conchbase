# Security policy

Please do not publish credentials, private user data, or an unpatched vulnerability in a public issue. Use GitHub's private vulnerability reporting for this repository when enabled, or contact the maintainers through the account profile.

Conchbase is early software. Loopback binding is the default and requires no token. A non-loopback bind is an explicit opt-in that requires `CONCHBASE_ALLOW_AUTHENTICATED_REMOTE_BINDING=1` and an approved bearer-token digest; unauthenticated requests return `401`. This is not a production agent runtime or remote pairing UX. Provider credentials stay in Magpie's own configuration.

The bounded composition executor does not call a model provider, load Skills/MCP/plugins, resolve secrets, or execute real host tools. The public tool request/approval ledger stores normalized, digest-only request and decision records plus durable audit events; it does not execute tools, grant capabilities, or treat an approval as execution permission. ADR 0019's provider observation boundary is transient and explicit: one bounded non-streaming function tool call can be normalized by the provider or the observation route, but no observation creates a ledger request, grants a capability, or executes a tool. The live v1 task path fails visibly on an untrusted observation. Streaming tool-call accumulation, real executor isolation, crash-safe side effects, and public tool execution remain separate accepted-contract work.

[ADR 0024](docs/decisions/0024-durable-work-domain-and-public-api.md) is the historical first deterministic work slice. [ADR 0025](docs/decisions/0025-local-first-v1-platform.md) adds durable start/stop/complete, restart recovery, Outbox/DeliveryReceipt decisions, a local Source with allow/deny policy, a capability directory, pairing/token metadata, bounded work events, and write-only SecretHandles. Runtime state remains authoritative; no model, real tool, external write, or generic secret resolver is added.

[ADR 0023](docs/decisions/0023-secret-handle-and-runtime-injection-proposal.md) remains a historical proposal. ADR 0025 implements process-scoped AES-256-GCM sealed handles with a one-way digest, a runtime-owned fixed adapter, and digest-only use receipts. Plaintext never enters model context, prompts, task state, durable events, logs, errors, client responses, Agent definitions, configuration documents, or browser state. A restart invalidates previously sealed values; stale use requests return `denied`. Current provider credentials stay in Magpie.

> Final local-first target: Conchbase `1.0.0` and ADR 0025 close the exact 47-path platform contract. Write-only SecretHandle values are sealed at rest with a process-scoped AES-256-GCM key, exposed only to one runtime-owned fixed adapter, and never returned, logged, or sent to a model, client, event, or UI. Restart invalidates previously sealed values; cross-process key sources, real external adapters, executors, Sources, external writes, and tools require separate ADRs.
